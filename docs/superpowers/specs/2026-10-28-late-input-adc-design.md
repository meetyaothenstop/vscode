# FAST输入电压晚采样对照

用户已同意先独立验证采样时序，再单独测试7V输出保护线。本轮完成第一阶段；
保持6V目标对应6.6V输出保护、10–14V输入窗口、0.5A电流参考及1.5A采样过流。

## 实现选择

- 整体后移ADC1触发会同时改变电感电流和输出反馈的采样相位，不适合作为只改输入采样的对照。
- ADC1注入不连续序列可分时触发，但丢触发会产生跨周期相位错位，新增重同步负担。
- 采用ADC2单通道规则采样同一PA0/ADC12_IN1，在Timer A CMP4=23040（4.8µs）
  经HRTIM TRG1触发。此机制为实现选择，无新增接线；ADC1注入TRG2及三路原顺序保持。

ADC2独立初始化、单端校准，使用与ADC1相同37.5MHz时钟和24.5周期采样时间，
单次外部触发、无DMA和ADC中断。在PWM计数器启动之前就绪。
采样/转换37周期及最大2.5周期触发延迟后，计算完成时刻约5.853µs，距周期末约0.813µs；
这些是时序计算，不是板上验证。

## 数据与保护约束

仅FAST启用晚输入ADC。运行中输入电压、前馈、启动资格与故障快照均使用ADC2新数据，
电流和右输出继续使用ADC1 JDR1/JDR3。缺少EOC/EOS或出现OVR时不得退回早采样，
活动阶段立即按ADC故障关断；停止阶段取消样本有效资格。每周期消费后清除完成/溢出标志。
初始化任一HAL步骤失败时不启动计数器且输出保持禁用。

继续维护同一个MDK-ARM/bench12_buck_fast.uvprojx；同目录Git分支保存历史，
不复制工程，既有未提交IDE设置保留。OLED标识区分晚采样对照版。

## 验证及分阶段交付

主机测试先证实原实现不能满足独立晚采样，再覆盖配置/数据选择、过期/丢失/溢出、
启动及运行输入边界、初始化失败、原过流/过压/时序保护。运行完整回归并重建唯一Keil目标，
核对CCM放置及中断反汇编。主机结果不证明去噪或板上周期预算。
板上先比较未启动PWM时ADC1/ADC2直流读数，再按12V限流0.2A、100Ω负载验证。
只有这项对照完成后才切换7V输出保护试验；本轮不把两项同时放入待测固件。

## 参考

- STM32G474 DS12288：PA0为ADC12_IN1；异步触发延迟1.5–2.5 ADC周期。
- ST HAL本地源码：ADC1/2规则组支持HRTIM TRG1，ADC1注入组保留HRTIM TRG2；
  ADC DR读取清除EOC，EOS/OVR须显式清除。
