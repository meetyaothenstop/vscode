# 正向Buck/Boost统一输入采样

用户要求直接把两种正向模式的输入电压采样统一，并询问触发是否跟随开关边沿。采用Buck已有的ADC2/PA0固定延后相位：PWM周期起点后23040 HRTIM ticks，即4.8us触发。此值是触发相位，实际采样与转换还存在ADC延迟，不声称4.8us就是转换完成时刻，也不动态跟随CMP1开关边沿。

范围：MAIN mode1/mode2的启动请求、有效性、启动准备、自举、装载、预充、换向、运行保护和worker输入全部采用ADC2输入样本；当前/输出仍ADC1第1/3通道。ADC2无效时拒绝启动或按现有ADC故障关断，不能回退到ADC1。反向mode3/mode4继续原ADC1语义，包括左侧输出残压校验。STOP/清故障后继续要求新的有效ADC2样本。

保持：主工程及唯一bench、150kHz PWM/ADC/快速保护、正向Boost25/5kHz和其他模式50/10kHz、PI与电气/时序保护门限；不移动ADC1序列，不改变硬件OCP未确认状态，不操作下载。菜单A2标识用于确认版本。

验证：两路读数不一致时以ADC2为准；ADC2低于10V仍保护；四种无效标志在全部启动/运行阶段及换向阻止输出；重启不复用样本；独立验证反向继续ADC1且排空未使用ADC2。真实worker接收新的输入源，完整回归及主/bench ARM实际镜像验证。主机合成数据仅验证软件选择，不证明实板欠压为误报。
