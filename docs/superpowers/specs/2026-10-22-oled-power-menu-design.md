# 四按键 OLED 电源菜单设计

日期：2026-10-22。用户已确认执行，并要求取消手动 Buck/Boost 选择页。

## 已确认的行为

修改外层工程 C:/Users/k/Desktop/keil/hal/bidreaction，参考 Encoder_PWM 的按键消抖、选择箭头和页面切换。

- 首页只有 forward、reverse；确认后直接进入该方向的参数页。
- 按已确认设定自动判断模式：output_v < input_v 为 Buck，output_v > input_v 为 Boost。相等显示 SET VIN != VOUT，不启动；现有控制器没有等压旁路模式。
- KEY1 / KEY2 上下循环选择，编辑时每次加减 1 V；KEY3 进入、编辑、确认、启动或停止；KEY4 取消未确认的编辑或返回首页，运行中返回先停止。
- 参数页仅选择左列 input_v、output_v、start/stop。右列 IL、intput_ret、output_ret 为实时数据，保留用户指定拼写。
- input_v 记录外部电源的标称输入；output_v 是闭环输出目标。实际启动仍由现有 API 检查 ADC 实测输入关系及全部原有条件。
- 正反向分别保存一组参数，仅保存在 RAM；默认 forward 为 12→36 V，reverse 为 36→12 V。
- input_v 范围 6～40 V，output_v 范围 1～36 V。编辑临时值在 KEY3 确认后生效，KEY4 取消。启动或运行中禁止编辑。
- reverse 页面已由后续反向集成接入模式 3/4，按设置自动选择 Buck/Boost；以 `PWM使用说明.md` 和 `2026-10-22-reverse-integration.md` 的当前行为为准。
- 启动准备或运行中将 start 显示为 stop，确认执行停止。故障保持锁存并显示故障码，菜单不隐式清故障或重启。
- 同时按下多个按键只处理一个，优先级：返回、确认、向上、向下。无长按连发。

## 128×64 布局

沿用 SSD1306 / I2C1 / 6×8 字体。21 个字符共 126 像素；右列从 x=66 开始，10 字符标签完整显示。

| y | 左列 | 右列 |
| --- | --- | --- |
| 0 | 标题与自动模式，例如 FORWARD BOOST，占整行 | |
| 8 | >input_v | IL |
| 16 | 12 V | +0.00 A |
| 24 | output_v | intput_ret |
| 32 | 36 V | 12.00 V |
| 40 | start / stop | output_ret |
| 48 | 留空 | 0.00 V |
| 56 | 状态或提示，占整行 | |

编辑使用 * 标记并显示临时值；标题模式始终按已确认设置判断。forward 输入/输出对应左/右测量电压，reverse 对应右/左。IL 保留左到右为正的符号。无有效采样显示 --。

数据约 200 ms 更新。按键或控制状态改变请求重画；整帧先画入 RAM，每轮前台服务最多发送一页，传输间继续服务电源与按键。字符串绘制不触发整帧刷新，OLED 格式化和传输不关闭控制中断。

## 代码结构与边界

- power_menu.c/.h：不依赖 HAL 的页面、按键、编辑、自动模式、动作与 8×21 字符帧。
- power_ui.c/.h：真实按键、电源 API、ADC 测量、OLED 缓冲区及逐页传输适配。
- 复用 Power_Service 已提供的一致测量；补充只读启动待处理/采样有效查询，避免为 UI 暂停控制中断。
- main.c 仅在 USER CODE 区接入；Keil 工程加入新文件，操作说明更新。
- 参考项目、嵌套副本、PI、PWM、保护门槛和启动条件不变。上电输出保持关闭，确认 start 才请求启动。
