# Live OLED Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** FAST运行态5Hz显示实时遥测，控制和按键不等屏幕传输。
**Architecture:** 现有OLED驱动内的单页DMA状态机，前台推进、ISR仅标记；启动期间静默。
**Tech Stack:** STM32G474 HAL I2C1/DMA1/DMAMUX、Keil6.18、GCC主机边界测试。
**Spec:** docs/superpowers/specs/2026-10-29-live-oled-design.md

## Global Constraints

- 单一bench12_buck_fast工程；原IDE未提交设置不覆盖或提交。
- 功率算法和保护不变；HRTIM0、显示IRQ3；无全局关中断或轮询等待新增。
- 异步缓冲不可提前复用；50ms超时仅显示离线；不冒充板测。

## Review Focus

- HAL_BUSY不造成错误重试或提前推进；DMA数据不引用栈/可变绘图RAM。
- 刷新中STOP/FAULT/启动请求能立即处理，后续整帧不混用页号。
- 错误/丢回调/时钟回绕不阻塞；迟到/非本I2C回调不重新启动传输。
- DMA路由、NVIC优先级及向量真正进入ARM映像；旧配置不变。
