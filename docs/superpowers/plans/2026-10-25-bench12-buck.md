# 12 V forward Buck bench implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Generate an isolated, restricted software-protection-only bench image.
**Architecture:** Opt-in build configuration sets operating limits and permits
missing hardware readiness only in this build. Hardware readiness is never
fabricated. Backend validates every start path and checks source voltage
while operating; menu identifies the build and defaults to 12->6 V.
**Tech Stack:** STM32G474 HAL/HRTIM, C11 host tests, Keil Armclang 6.18.
**Spec:** ../specs/2026-10-25-bench12-buck-design.md

## Global Constraints

- POWER_BENCH_12V_BUCK_TEST defaults to 0.
- Test: mode 1 only, input 10.5-13.5 V, output 1-6 V, reference 0.5 A,
  sampled absolute trip 1.5 A; protection_ready stays 0 without comparators.
- Default readiness guard and existing software protections remain active.
- Separate project and output; no hardware download or automatic start.

## Review Focus

- Debugger commands and direct API requests cannot bypass test restrictions.
- Input changing between request acceptance and arming causes shutdown.
- Invalid/nonfinite targets, missing ADC events, and rail currents stop outputs.
- Fault clear/stop never resumes PWM, including pending starts.
- Hardware-readiness display remains truthful; default build is unaffected.
