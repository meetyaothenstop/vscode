## 最新9V故障现场

来源：用户截图`codex-clipboard-42491800-c27b-4133-9d7c-c222101ef2c9.png`，随后明确回复“设定9V”。
截图符号`&power_status=0x20000B10`与本地W128 MAP一致，但不是整片Flash指纹核验。
本轮只读本地代码和用户截图，没有替用户执行截图Command中的LOAD或任何板上操作。

| 字段 | 截图值 |
| --- | --- |
| state / fault / fault_detail | POWER_FAULT / 4 / 0 |
| 用户确认目标 / v_reference | 9V / 9V |
| fault_v_left | 24.0211468V |
| fault_v_right | 11.5719309V |
| fault_il | −0.141685486A（固定相位采样，不等于负载平均电流） |
| d_cmd | 0.393263996 |
| left_compare / right_compare | 0x2D89=11657 / 0x6E00=28160 |
| isr_cycles_max | 0x34F=847CPU周期，约5.647us |
| fault_elapsed / spacing / counter | 全0，本次不是时序故障 |
| samples（实时计数） | 0x24B986=2406790，不等于成功控制步数 |

9×1.25=11.25V，故障采样超线0.3219309V，判据吻合；不能直接将此浮点采样认作同次真实端电压。
参考已推进到9V，已跨过首次控制计算；尚不能据一张截图证明连续稳态或整体时序通过。
847是已完成路径在写后检查点的DWT最大值，不能与写前840直接比较，也不包含全部异常返回。
保留指令不在0/0.95限幅；按源映射得到11657/28160，与截图比较值一致，但不证明PI积分状态正常。
顶部实时`v_right=0`/raw_vl0来自故障后遥测，不能代替`fault_v_right`；`power_diag.fault`
无法求值符合当前无插桩构建，不是ADC不工作的证据。

下一步保留同一现场，展开`forward_U`和`forward_B`，优先取得：

```text
forward_U.V_right
forward_U.V_left
forward_U.IL
forward_B.Product2
forward_B.Saturation
forward_B.DiscreteIntegrator
forward_B.DiscreteIntegrator1
```

这些对象在故障后不再执行控制步，因此是前一已完成控制步的输入/PI结果。
比较`forward_U.V_right`与故障11.5719309V，以及电压误差/电流参考/两个积分项，
判断此前已持续看到高电压，还是新采样突然跳高。仍需同次输出/PA1波形判定电气过冲与采样瞬态，
不能只凭此次电流为负、指令未限幅或名义模型通过就排除控制问题。

## 同次故障的前一步控制状态

用户继续提供`codex-clipboard-e947c93f-8ca3-4a99-b773-34365ddc65e9.png`，并明确确认与前一张
故障截图属于同一次故障，期间没有复位、清故障或重新启动。以下状态可关联分析，仍未取得电气波形。

| 前一已完成控制步字段 | 截图值 |
| --- | --- |
| forward_U.V_left / V_right | 23.9685459V / 10.0994549V |
| forward_U.IL / mode | 0.246299744A / 1 |
| forward_B.DiscreteIntegrator3 / Saturation4 | 9 / 9 |
| forward_B.Saturation3（前馈） | 0.375492126 |
| forward_B.DiscreteIntegrator（外环积分） | 0.71421355 |
| forward_B.Saturation（电流参考） | 0.390101403A |
| forward_B.DiscreteIntegrator1（内环积分） | 0.0156148393 |
| forward_B.Saturation2（最终指令） | 0.393263996 |

电流环可以直接用独立截图数据核对：

```text
电流误差 = 0.390101403 - 0.246299744 = 0.143801659A
D = 0.375492126 + 0.015 * 0.143801659 + 0.0156148393
  = 0.393263990185，和记录0.393263996在浮点精度内一致
```

`Product2`在本图下方未显示；按现有代码且电流参考未碰0/6A限幅，可反推电压误差约
`(0.390101403-0.71421355)/0.3=-1.08037382V`，滤波输出约10.08037382V。
这是由公式反推，不是直接读取`Product2`或独立验证外环滤波器状态。
电压反馈方向并未表现为完全忽略高输出；外环积分项仍使电流参考保持正值，
但正积分和正电流参考本身不等于积分饱和，也不能脱离负载与固定采样相位认定其过大。

更需核实的量是：同次前一步采样10.0994549V到故障采样11.5719309V，差1.472476V。
按当前代码/连续采样时序，它们应对应相邻PWM周期，约6.667us；并无外部时间测量确认。
若将此解释为标称460uF电容内部电压在一周期内整体上升，则`C*dV/dt≈101.6A`为平均净充电流。
这个估算不含端电压的ESR/寄生尖峰，也不能用两次固定相位电流排除其间的真实大尖峰；
用途是说明应优先同步测量端电压与ADC引脚，不能直接判定ADC误报或宣称实际电流达到102A。

下一步由用户在原低功率条件下同步抓：CH1输出电容端对板地，CH2 PA1采样点对板地。
按当前0.04666换算，9V保护线对应PA1约0.524925V，可先约0.52V上升沿单次触发，
用5–10us/div观察短暂跃变，再用较慢时基（如10–20ms/div，按实际持续时间调整）看整体上升过程。
探头应避免长接地线引入伪尖峰；也记录探头接入后故障是否改变，避免忽略测量负载的影响。
这些为待执行的测量建议，本轮没有操作示波器或重新启动板子。

ST [AN2834第4.4节](https://www.st.com/resource/en/application_note/cd00211314.pdf)说明，高源阻抗与
ADC采样电路瞬态可能形成附加测量误差；本板源阻抗/相关瞬态尚未核验，不能据此直接定因或先改RC/采样时间。
若输出端与PA1均显示同比例越限，继续分析真实控制/功率级过冲；若主要在PA1出现尖峰，
优先查分压/地/采样时序；若引脚未越限而ADC仍越限，还须检查参考电源、获取时间及读取一致性。
本轮保留现有PI和保护，不生成新固件；本次只完成算术及证据边界分析。

## 现有模型对照（不等于板测）

## 最小现场数据

保留现有故障，不为读取先复位/清故障，提供同次目标和`power_status`中的：

```text
fault
fault_v_right
fault_raw_vl
fault_il
v_reference
d_cmd
```

`fault_*`是首故障采样锁存；顶部实时`v_right`会继续变化。
`v_reference`/`d_cmd`是前一控制步留下的参考/指令，STOP可清零，不能当作故障当次新PI计算。
以11V为例：先核对故障锁存是否确实>13.75V；参考仍很低与接近11V的两种现场，后续排查方向不同。
若原始码与换算吻合，还需输出端和PA1采样点的同次波形，区分真实输出过冲与采样瞬态。
OLED约200ms调度、分页DMA且启动抑制新刷新，单次闪动不能确定故障发生于哪一电气阶段。

本轮仅软件对照与文档记录，没有改变PI/保护/固件，没有连接、下载或操作板子。
