# 默认电压配置整理与验证（2026-11-07）

## 修改入口

统一文件：`Core/Inc/power_build_config.h`，搜索`Power-on menu defaults`。
主工程使用紧随`#if POWER_MAIN_APPLICATION`的四个宏：

| 宏 | 当前默认值 | 用途 |
| --- | --- | --- |
| `POWER_FORWARD_DEFAULT_INPUT_VOLTS` | 24U | 正向输入设定 |
| `POWER_FORWARD_DEFAULT_OUTPUT_VOLTS` | 12U | 正向输出目标 |
| `POWER_REVERSE_DEFAULT_INPUT_VOLTS` | 12U | 反向输入设定 |
| `POWER_REVERSE_DEFAULT_OUTPUT_VOLTS` | 6U | 反向输出目标 |

输入设定决定菜单选择Buck还是Boost，实际输入和启动校验仍使用ADC采样。
`Menu_Init()`只引用配置宏，不再单独保存反向电压常量。
调试邮箱`power_target_volts`继续默认取正向输出值；反向菜单目标不会自动改写此独立邮箱。
这些默认值在初始化时装入RAM，按键修改不永久保存。
Boost参考起点仍由启动时实测输入配置，Buck仍从0.1V起步。
