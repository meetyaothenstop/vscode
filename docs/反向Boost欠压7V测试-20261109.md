# 反向Boost欠压7V试验（2026-11-09）

用户确认右侧12V输入、电源限流0.9A、100Ω负载、目标18V，报错2/IN8.99V；
明确要求降低欠压到7V试验。本轮只调整当前测试的MAIN反向Boost(mode4)，
输入窗7～42V；正向Buck/Boost与反向Buck仍9～42V，唯一受限bench保持。

配置：`Core/Inc/power_build_config.h`中
`POWER_MAIN_REVERSE_BOOST_INPUT_MIN_VOLTS=7.0f`。
`MODE_INPUT_MIN_VOLTS(mode)`同时用于请求校验和`active_limits`缓存，
准备、自举、装载、预充、换向、运行及HOLD/恢复均沿用该缓存的实际输入保护。
没有给欠压增加延时或屏蔽，仍按每个150kHz新样本立即判断。

反向ADC1右侧输入/左侧输出、两Boost25/5kHz计算、Buck50/10kHz、
PWM/ADC/快速保护150kHz、连续PI、启动严格|IL|<1A、输出残压≤3V、
OVP及42V输入上限、采样过流7.5A与方向保护保持。
保留用户默认：正向18→3V、反向12→18V。
首页`MAIN ADC B25/5 R7`，反向Boost页`REVERSE BOOST R25V7`。

## 试验边界

若负载确为100Ω，18V稳态需要3.24W，12V/90%效率估算输入0.30A，
不能沿用此前36V/100Ω时0.9A不足以维持稳态的结论。
目前只确认9V版本采到了8.99V，尚无电源CC/板端瞬态波形或同步ADC证据，
未区分真实压降与采样干扰。7V是用户要求的软件门限试验，不证明这些物理原因已解决，
也不证明7V输入下的驱动供电或实板运行就绪。
