# 主工程正向Buck OVP1.5候选 — 2026-10-31

> 本文保留未封顶1.5版本历史。用户后续要求超过40V的门限自动设为40V，当前实现见
> [40V封顶测试](正向Buck过压40V封顶测试.md)；下文54V仅为旧策略记录。

用户明确要求“将正向buck的过压保护转为1.5”。沿用`MDK-ARM/bidreaction.uvprojx`，
Target`bidreaction`，下载文件`MDK-ARM/bidreaction/bidreaction.hex`，由用户操作下载。
首页`MAIN ADC OVP1.5 6A`、参数页`M-OV1.5`，诊断宏0。

## 规则及范围

| 模式 | 目标乘数 | 示例 |
| --- | --- | --- |
| MAIN正向Buck | 1.5 | 6V→9V、9V→13.5V、11V→16.5V、12V→18V |
| MAIN反向Buck | 原1.25 | 12V→15V |
| MAIN正/反Boost | 原1.1 | 36V→39.6V |
| 唯一受限台架 | 原规则 | 当前24V档12V→15V，实际HEX保持不变 |

只在接受启动时选择正向专用倍率并缓存输出停机电压，现有IRQ的严格`>`比较和单次采样关断不改。
0V关闭、冷启动、首故障保持、6A参考/7.5A采样停机、PI/软启动、四模式、ADC/PWM150kHz及W128时序保持。
正向Buck新常量独立于原共享Buck1.25常量，避免连带改变反向Buck。

**已知硬件限制：36V×1.5=54V，超过用户此前提供的50V电容额定。**
本轮按用户要求实现确切1.5比例，没有暗中加电压上限或删除原目标范围；54V边界只在主机寄存器夹具验证，
不代表板子可承受54V。本候选供当前24V低功率条件测试，不据此进入36V或其他高压验证。
当前硬件OCP仍未确认；这次倍率调整也不验证硬件保护、波形或最坏中断返回余量。

## 用户测试

由用户保存旧9V故障数据、保持输出关闭后下载上述主HEX，并核对新首页/参数页。
沿用原24V输入、原低功率负载，先设置原9V目标；实接负载/电源限流以现场确认为准。
记录实际输出、OLED显示、运行时间及波形。旧11.5719309V样本低于新门限只说明保护放宽；
若实际输出持续明显高于9V，也不能算作稳压成功。
若再报4，保留`power_status.fault_v_right`/`fault_raw_vl`及`forward_U`/`forward_B`，
区分首次越限与后续遥测；当前MAP的`power_status`仍为0x20000B10，以新AXF/MAP为准。
原9V故障的采样跃变与PI状态分析保留在[低目标排查](低目标输出保护排查.md)，根因仍待模拟波形确认。

本轮没有连接、下载、运行、暂停、复位、清故障或启动板子，尚未验证新倍率的实板结果。
