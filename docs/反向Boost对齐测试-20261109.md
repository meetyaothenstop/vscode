# 反向 Boost 门限与25/5kHz对齐（2026-11-09）

用户要求准备反向输入，将检查对齐正向Boost，并明确补充控制频率。
继续使用主工程`MDK-ARM/bidreaction.uvprojx`，不新建工程；下载由用户操作。

## 修改范围

|项目|MAIN反向Boost现在|修改前|
|---|---|---|
|实测输入窗口|9～42V|6～40V|
|冷启动电流|严格\|IL\|<1A|<0.25A|
|冷启动左输出残压|≤3V|≤0.25V|
|左输出过压|min(max(最终目标×1.5,6V),40V)|目标×1.1|
|电流/电压计算|25/5kHz，40/200us|50/10kHz，20/100us|
|后台请求/T7截止|每6个PWM/40us，超期仍关断|每3个PWM/20us|

四模式统一引用既有`POWER_MAIN_BUCK_*`门限组，名称保留以减少无关改动。
Boost目标仍须高于实测输入，范围1～36V，0V目标仍拒绝；Buck0.95可达性保持。
输入窗口上限42V不表示能在42V输入、36V目标下升压启动。

反向仍以ADC1右电压为输入、ADC1左电压为输出，IL正常为负；不改为左侧ADC2。
ADC2固定4.8us仍只供正向两模式输入。电流参考6A、采样绝对过流7.5A、
反向异常正电流>1A连续16样本、HOLD恢复|IL|<0.25A及其他保护保持。
启动1A是互锁，不是运行电流设定或电源限流值。

生产mode4 worker使用`reverse_main_boost_step/hold_step`，复用`boost_control_rates.h`。
积分步长40/200us、6238rad/s滤波按新周期；反向连续电压PI0.8/10、电流PI0.015/20保持。
反向参考在CTRL_RUN前保持、120V/s参考斜坡、500A/s预充、100/s接管保持原逻辑。
公共`reverse_step/hold_step`仍为50/10kHz兼容入口（单速率配置150kHz），不用于生产mode4。
PWM/ADC/快速软件保护150kHz；两个Buck50/10kHz；原正向Boost25/5kHz保持。
换向仍至少3个完整PWM全关断，并等待新Boost计划生效，不保证固定20us交接。

保留用户当前默认：正向18→3V，反向12→6V。后者默认选择反向Buck，
测试反向Boost时在菜单选择reverse并设置输入12V、输出24V等有效升压目标；
这里是菜单设置说明，不是实板运行已验证的结论。
首页`MAIN ADC B25/5 R1`，反向Boost页`REVERSE BOOST R25V9`，正向Boost页仍B25A2。
