# RAW1反向12→6V、100Ω故障16现场

2026-11-03。固件源码/标签为4f69eff4fac3cffba642e1a76ba3896ca2fa0d37 / main-fastirq-raw1-20261103。
本记录不修改固件。用户反馈按启动后万用表到6V，OLED停更，数秒后刷新并报16；负载100Ω。
用户随后授权助手操作Keil，助手仅在原有已暂停调试现场添加/展开Watch观察项。
没有运行、单步、暂停、复位、清故障、下载或写入目标变量；保留原调试现场和原Watch项。

反向方向保护为连续16个150kHz样本高于+1A，约106.7us。仅最后一个样本被锁存，
不能据此重建16个原始样本波形，也不能证明采样值等于真实瞬时电流。
6V/100Ω平均负载电流约60mA，不等同固定相位电感电流采样。

## 只读补齐的状态

按本版最终map核对，且power_status仍位于0x20000BA0：

| 字段 | 本版只读表达式/来源 | 值 |
| --- | --- | --- |
| bootstrap_resume | *((unsigned char *)0x200001B8) | 1 |
| bootstrap_cycles | *((unsigned int *)0x2000021C) | 0 |
| arming_cycles | *((unsigned int *)0x20000290) | 0 |
| v_reference | 展开power_status第二个匿名联合 | 4.18981647V |

地址仅适用于当前AXF，SHA256为16836826F5B92C5DE67BA33F8AC79FE832830903AF7B206138C6DDF37B82E720。
原Watch中0x200001B0/0x200001FC不是上述正确地址；其0/4不能用于判断恢复阶段。
直接输入三个文件内静态变量名不能求值，是调试可见性问题，不是固件运行报错。

bootstrap_resume在一次HOLD恢复时置1，直到后续启动等路径才重新设置。
因此它证明本次启动后曾恢复，不证明故障发生在刚恢复瞬间。两个剩余计数为0，
结合mode3排除尚未完成的自举/装载等待；故障前究竟是RUNNING还是再次HOLD未独立锁存。

最后一次后台状态（不是fault同一时刻的额外原子快照）：

| 字段 | 值 |

| reverse_U.mode / V_left / V_right / IL | 3 / 5.24257135V / 12.0396585V / +1.2324295A |
| reverse_B.Saturation4 / Product3 | 4.18981647V / -0.934297562V |
| reverse_B.Saturation / Gain2 | 0 / -0（电流参考为0） |

当前公式Saturation1=参考/右输入，d_cmd=0.015*Sum3+电流积分+Saturation1，
与现场值一致；未发现这组数据的算术/比较值映射不一致。输出采样高于参考，
电压环请求0电流。为何出现约1V偏离以及持续正向采样，仍需区分电气过程、采样与状态切换。

## 时序与OLED

150MHz，单位周期除150得到us：

| 字段 | 十六进制/十进制 | 时间 |
| --- | --- | --- |
| fast_run_cycles_max / isr_cycles_max | 0x2B3 / 691 | 4.607us |
| control_cycles_max | 0xA78 / 2680 | 17.867us |
| control_start_delay_max | 0x617 / 1559 | 10.393us |
| control_run_wall_cycles_max | 0x806 / 2054 | 13.693us |
| control_fast_c_cycles_max | 0x39A / 922 | 6.147us |

最大值可能来自不同请求，不可相加/相减重建单次占用。完成检查点峰值接近20us窗口，
但不包含全部异常进出/发布收尾，也不能由峰值估算持续CPU占用。本次记录不是T7。
源码允许RUNNING/HOLD刷新OLED，前台PowerUI_Service与HAL_Delay依赖获得运行时间及SysTick。
当前没有前台间隔/运行时间统计，不能断言停更由CPU饥饿、SysTick或I2C中的哪一项造成。
助手接手时目标已暂停于HAL_Delay；这个暂停位置不能证明故障前前台长期被阻塞。

## 补充主机实验

原实际后台名义开关模型单工况0.6秒，延长反向12.056982→6V、100Ω到3秒：

| 条件 | 结果 |
| --- | --- |
| 原立即发布模型 | 输出6.005V、峰6.010V，无故障 |
| 0.5秒时输出扰动到6.04V，真实状态机HOLD及恢复 | 输出6.004V、峰6.040V，HOLD/恢复各1次，无故障 |
| worker仅每3PWM周期末尾指定相位发布 | 输出6.002V、峰6.009V，无故障 |
| 同一延后发布模型加6.04V扰动 | 输出6.006V、HOLD/恢复各1次，无故障 |

使用真实控制器/后台，仍为原22uH/460uF/50mΩ理想模型；每PWM200积分步。
临时实验位于忽略目录.superpowers/fastirq-raw，未改动原测试、固件或保护门限。
这些实验未复现本次现场，不能作为实板稳定性或恢复正确性的证明。
下一步应针对带电输出下的恢复/运行瞬态、电流采样真实性及前台实际运行间隔取证；
本记录不预先认定降低控制频率、放宽16或某项单独代码调整能解决问题。
