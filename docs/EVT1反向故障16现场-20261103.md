# EVT1反向12→6V故障16现场

2026-11-03。固件5b242c7c5e41273c6d195c40af8c3acc84c4d62e，标签main-eventdiag1-20261103。
用户沿用反向12→6V、100Ω测试并提供截图；助手在既有已暂停的Keil现场仅添加/展开power_event.fault。
没有运行、暂停、单步、复位、下载、清故障或写目标变量；本次不修改固件，原现场保留。
旧RAW1绝对地址在EVT1中失效，原Watch中0x2000021C等数值不能解释成旧自举变量。

## 界面问题的主机复现

power_ui.c在状态变化时重置next_page为MENU_ROWS，STARTING静默路径也重置；重返RUNNING便重画并从第0页开始。
临时探针复用真实power_ui.c/power_menu.c和main_ui_test夹具，模拟400组BOOTSTRAP/RUNNING交替，HAL传输始终OK，
断言第7页应有提交。结果失败：第0页401次，第1/2页各1次（含循环前菜单准备），第3～7页均0。
探针/日志在忽略目录.superpowers/eventdiag/ui-churn.c/.log。这证明状态频繁变化可以使后续页饥饿，
不依赖前台数秒停摆；仍需修复后的板测确认是否为实板界面的主因。
修复必须兼顾启动静默、不可变DMA快照及静默期间命令包被取消后的重试，不能简单去掉所有重置。

## 边界与下一步

真实回流/采样异常尚未区分；16保护保持。电流故障发生于恢复后的RUNNING，不能再用旧自举变量猜测阶段。
原文档记载电压前端100Ω/470nF约47us；将名义模型加入该电压一阶环节并延长到12秒，仍无故障，输出6.004V、峰6.010V。
这只是探索实验，未核实当前左输出模拟前端/电容实际参数，不证明板上稳定性。
本次不修改频率、PI、门限或UI行为；未验证板上最坏时序或硬件OCP接线。
