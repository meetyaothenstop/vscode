## 当前规则

```text
MAIN正向Buck过压线 = min(本次启动目标电压 * 1.5, 40.0V)
ADC输出换算值 > 过压线：首次采样立即停机并锁存故障4
```

| 目标电压 | 正向Buck过压线 |
| --- | --- |
| 9V | 13.5V |
| 12V | 18V |
| 24V | 36V |
| 26V | 39V |
| 27V、30V、36V | 40V |

门限在接受请求时缓存，软启动过程中沿用最终目标计算的门限。
反向Buck保持1.25倍（36V目标仍45V），Boost保持1.1倍，台架规则/HEX不变；40V上限仅作用于MAIN正向Buck。
0V关断、目标0–36V、实际输入关系、6A参考/7.5A采样停机、PI/软启动、ADC/PWM和W128保护策略保持。
