# 主工程反向Buck12V→6V候选 — 2026-11-02

按用户要求，先准备右侧12V输入、左侧6V输出的反向Buck，保护参照当前正向Buck，重点检查时序。
仍使用`MDK-ARM/bidreaction.uvprojx`、Target`bidreaction`；固件为
`MDK-ARM/bidreaction/bidreaction.hex`。保留正向Buck/Boost及反向Boost，不新建工程。
首页`MAIN ADC RBUCK12-6`、参数页`M-RB126`；反向菜单默认输入12V、输出6V。

## 控制与保护

| 项目 | 本版反向Buck |
| --- | --- |
| 功率方向 | 右侧Timer A/PA8、PA9输入；左侧Timer B/PA10、PA11输出 |
| 实际输入保护 | 右侧10–42V，启动及运行检查；目标≤实际输入×0.95 |
| 输出过压 | 左侧min(max(最终目标×1.5,6V),40V)；6V目标为9V |
| 冷启动条件 | 电流绝对值<1A，左输出残压≤3V；准备各阶段重新核对 |
| 电流方向与保护 | IL负值表示正常反向；参考幅值≤6A，采样绝对值≥7.5A停机 |
| 错误极性 | 原反向连续16次采样IL>+1A保护保持 |
| 关断 | 0V仍关闭四路输出；STOP/首故障锁存/硬件故障锁存保持 |

正反Buck现在共用上述输入/输出/冷启动规则。正向数值不变，Boost仍输入6–40V、输出目标×1.1、
冷启动0.25A/0.25V。反向范围仍由主工程保留，当前交付先供12→6V验证，不宣称全范围实板通过。
3V是冷启动残压上限，软启动仍由0.1V开始，斜率及原反向PI参数保持。
30周期自举、2周期arming、PWM150kHz及死区保持；右侧源桥采用原零占空比策略，左侧保留自举刷新。

反向Buck使用共享模板生成的`reverse_main_buck_step`，省去Boost预充电、延时及多余滤波/斜坡状态。
`reverse_main_full_step`保留完整反向Boost路径；HOLD/恢复仍调用当前模式的控制步。
Buck比较值计算内联，保留原映射结果和无效值检查。Watch中Boost专用状态在Buck模式可能保持初值，
不能将其误认为Buck PI未运行。

## 用户下载及取数

由用户下载主HEX并核对新首页。进入reverse参数页，默认12V/6V，选择start启动。
右侧供电、左侧为输出；反向正常IL显示负值。调试邮箱方式需先设`power_target_volts=6`，再提交命令5。
若发生故障，保留同一次`power_status`全部`fault_*`、`isr_cycles_max`及固件身份；
尤其时序故障看锁存的elapsed/spacing/counter，避免将关断后实时采样当作触发现场。

本轮没有连接、下载、启动、复位、暂停或清故障等板上操作。主工程仍是已授权的ADC软件保护测试，
硬件OCP接线/就绪、电流增益、实际波形、稳压与IRQ最坏耗时均需实板验证。
