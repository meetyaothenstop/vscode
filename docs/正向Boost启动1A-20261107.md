# MAIN正向Boost启动电流1A（2026-11-07）

## 请求与实现范围

用户在正向Boost测试中仍报128 S8，明确要求将启动电流检查也设为1A。
按当前上下文仅修改MAIN正向Boost（mode2），维持绝对值严格小于门限的比较。

入口：`Core/Inc/power_build_config.h`：

```c
#define POWER_MAIN_FORWARD_BOOST_START_CURRENT_LIMIT_AMPS 1.0f
```

`Power_RequestStart()`仅为MAIN mode2选择此值，并发布到已有`active_limits`和整数`raw_policy`。
请求S5及待启动、自举、装载阶段的S8因此共用1A门限，不在150kHz正常保护路径增加模式判断。
该设置不是运行限流，也不自动清错或重新启动。

| 模式 | 启动电流绝对值 | 启动输出残压上限 |
| --- | --- | --- |
| MAIN正向Buck | <1A | 3V |
| MAIN正向Boost | <1A（本次修改） | 0.25V |
| MAIN反向Buck | <1A | 3V |
| MAIN反向Boost | <0.25A | 0.25V |

原6A电流参考、7.5A采样过流、正向负电流保护、ADC/时序/硬件故障锁存保持。
预充、全关换向、PI、软启动、PWM/ADC150kHz、电流50kHz、电压10kHz保持。
唯一受限bench和普通历史配置继续使用原门限。
