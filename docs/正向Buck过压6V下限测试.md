# 主工程正向Buck过压6V下限候选 — 2026-11-02

本页记录b99b2b7。当前反向Buck也已对齐此保护规则，固件身份和下载记录见
[反向12→6V测试](反向Buck12V转6V测试.md)；以下历史指纹不代表当前版本。

用户在12V→3V时取得故障4截图：fault_v_left12.0105734V、fault_v_right4.72924709V、
fault_il−0.0770206451A，参考3V，raw_vl0x111=273。旧门限3×1.5=4.5V，
软件触发条件吻合；不能仅凭此断定实际过冲或采样偏高。
用户明确要求：目标低于6V时，如果原过压门限低于6V，统一提高到6V。

仍使用`MDK-ARM/bidreaction.uvprojx`，Target`bidreaction`，
HEX为`MDK-ARM/bidreaction/bidreaction.hex`，由用户下载。
首页`MAIN ADC OVP6-40`，参数页`M-OV640`，诊断宏0。

仅MAIN正向Buck在接受启动请求时计算并缓存门限。有效非零目标下等价于：

```text
OVP = min(max(目标电压 × 1.5, 6V), 40V)
输出ADC换算值 > OVP：首次越限立即停机，锁存故障4
```

| 目标 | 过压门限 |
| --- | --- |
| 1V、2V、3V、4V | 6V |
| 4.01V | 6.015V |
| 5V | 7.5V |
| 5.9V | 8.85V |
| 6V | 9V |
| 9V | 13.5V |
| 27V、30V、36V | 40V |

0V仍为关断，不套用过压下限。启动|IL|<1A/输出残压≤3V、准备时长和0.1V初始参考保持。
反向Buck仍×1.25，Boost仍×1.1；台架规则和HEX保持。IRQ仍比较已缓存的门限，
没有新增IRQ计算；原6A参考/7.5A采样过流、负向电流保护、PI/ADC/PWM及W128保持。
