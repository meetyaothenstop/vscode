# 反向Boost运行约16V且抖动：待实板状态证据

## 用户确认的现场

- 使用反向右侧输入；此前12V、电源限流0.9A、100Ω、目标18V时，9V欠压版报2/IN8.99V。
- 7V门限试验版d023414交付后，用户反馈现在可以RUNNING，但实测和OLED输出都在约16V且抖动较大。
- 用户确认抖动时输入显示12V；12V电源面板实际电流约0.3A，CC灯不亮。
- 这些反馈不证明板端瞬态输入恒定，也不能确定板上Flash与磁盘固件一致。尚未取得同步波形或控制状态。

100Ω在18V时稳态输出3.24W，12V/90%效率估算输入0.30A。当前面板观察不支持
持续撞0.9A限流的解释；瞬态供电问题仍不能由面板平均读数排除。

## 已核对源码

两Boost均25/5kHz计算，PWM/ADC/快速保护150kHz。反向与正向仍有差异：
电压PI0.8/10与0.3/8，Boost前馈倍率1与0.2，预充完成0.99Vin与0.90Vin，
输入ADC1右侧与ADC2左侧延后样本，电流正常符号为负与正。
本轮没有据此修改PI、前馈或保护。

MAIN反向在`POWER_RUNNING && control_run`下，单个有效输出ADC样本达到目标×1.005
即全关断进入HOLD。18V目标对应约18.09V。这一路未经过电压环的数字滤波。
低于目标×0.99且|IL|<0.25A才请求恢复；恢复会重置参考起点与PI，再经历自举/装载。
`power_ui.c`把POWER_RUNNING和POWER_HOLD都映射为菜单RUNNING，故页面不能区分两者。

## 主机机制试验，不能当成实板根因

使用当前d023414源码、真实快速/worker后端及现有22uH/460uF/100Ω名义开关模型：

- 无额外噪声，12→18V：实际模型输出17.995V；VinADC12.0050V、VoutADC17.9896V、参考18V、duty0.3332、IL采样−0.2548A，CTRL/BOOST均1。
- 在启动后人为给输出电压ADC每60个PWM插入一次+2.2V、单样本尖峰，保持模型输入理想12V：
  0.6秒内118次进入HOLD，后0.3秒物理模型输出平均15.8223V、范围15.7434～15.9283V；
  结束时参考17.0264V、duty0.2453、CTRL/BOOST均1，没有软件fault。
- +2.2V和每60PWM是人为构造的激励，**不是用户测到的尖峰幅值或频率**。
  试验只证明“输出ADC尖峰→HOLD/参考反复重置→约16V平均输出”的机制可发生，不能证明实板有该噪声或HOLD循环。
- 临时源码与输出在Git忽略的`.superpowers/reverse-boost-align/uv7/steady18_probe.c`、`hold_spike_probe.c`及配套EXE；未修改生产源码或交付新固件。

## 下一步所需证据

已请求用户保持连续运行、不暂停CPU，读取：
`power_status.state`（3=RUNNING、6=HOLD）、`power_status.v_reference`、
`power_status.d_cmd`、`power_status.il`、`reverse_Y.BOOST_RUN_R`。
HOLD可能短于Watch刷新周期，单次看到state3不能排除重复HOLD。
若无法读取Watch，可再准备OLED诊断版本，先取得真实状态证据再决定控制改动。

本轮没有操作板子、没有改变固件。实板振荡根因、最坏执行时间及硬件OCP仍未验证。
