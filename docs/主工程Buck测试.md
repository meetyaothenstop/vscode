## 配置与范围

| 项目 | 主工程Buck（正/反） | 主工程Boost（正/反） |
| --- | --- | --- |
| 输入菜单 | 12–40V，1V步进 | 同菜单 |
| 非零输出菜单/后端 | 1–36V，菜单1V步进 | 1–36V且目标高于实际输入 |
| 0V | 关闭四路PWM，负载被动放电 | 零请求按Buck OFF操作，非升压目标 |
| 电流参考上限 | 6A | 原6A |
| 采样过流停机 | 7.5A | 原7.5A |
| 实际采样输入保护 | 10–42V，覆盖标称端点误差 | 原6–40V |
| 输出过压 | 目标×1.25；36V对应45V | 原目标×1.1 |
| 冷启动 | 电流绝对值<0.5A、输出≤1V | 原<0.25A、输出≤0.25V |

主界面`MAIN ADC SW 6A`、参数页`SW-MAIN`。默认正向输入24V/目标12V、反向36V/12V。
界面按输入/输出设置选择Buck/Boost；实际启动仍核对采样输入，不能靠菜单设置伪装电源。
正向Buck最大Dcmd0.95，后端要求目标≤实际输入×0.95，运行中每次新样本也检查。
例如40→36V可达，12→36V是Boost工作点。反向Buck保持输出严格低于实际输入。

6A是电感采样电流控制参考的上限。7.5A是独立采样停机线；控制跟踪有纹波、延迟和超调，
不保证实际瞬时电流≤6A。硬件比较器通路尚未确认；当前由用户明确选择ADC软件保护测试，
未把protection_ready伪造为1。设`POWER_MAIN_ADC_SOFTWARE_ONLY=0`可恢复未就绪禁止启动，
本机默认未确认接线时会报512；只有验证接线后才能启用`POWER_OCP_WIRING_CONFIRMED`。

## 0V与调试命令

0V表示关闭所有门极输出并取消待启动，不是强制将带电输出电容瞬间拉到0V。
正向/反向Buck直接请求0或-0在STOP、准备、运行和FAULT均可执行；FAULT及首故障数据保持。
负数、NaN/无穷、0和1V之间的非零后端目标不作为OFF接受。

调试邮箱编号保持：1正向Boost、2停止、3清故障、4正向Buck、5反向Buck、6反向Boost。
要零关断，先设`power_target_volts=0`，再提交4或5。单改target不会实时改变当前运行目标。
正目标运行中不允许直接重启/改目标，先STOP，等待新鲜STOP阶段样本和残压/电流满足条件。
0V关断不清故障，也不绕过下次正目标冷启动检查。

## 采样、显示和模式保留

正向Buck用优化控制步；正向Boost用完整步，二者由单一私有模板编译生成，
U/B/X及初始化接口保持。反向step/hold/resume保留并迁入CCM。
正向Buck用ADC2在4.8µs的PA0输入采样，电流/右输出继续ADC1原采样；
活动Boost/反向使用原ADC1反馈时序。ADC2不用时仍消费标志，不能将旧ADC1样本误作晚样本重启。
OLED前台DMA约200ms调度一帧；启动期间不发新显示页，键/STOP优先，错误仅显示离线。
840周期写入/936周期收尾和相位检查保持，搬到CCM和主机测试都不等同板上耗时通过。
