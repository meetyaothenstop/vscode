# PWM 与正向闭环使用说明

本次修改的是外层 `bidreaction` 工程。Keil 工程为 `MDK-ARM/bidreaction.uvprojx`。

## 硬件前提

- PA0 / ADC_VH：左侧 H_VIN+ 电压；PA1 / ADC_VL：右侧 L_VIN+ 电压。
- PA2 / ADC_L：**电感电流**。新增 5 mΩ 电阻串在 SW_1 与 D4 左端之间，INA240A1 的 IN+ 接 SW_1 侧，IN− 接 D4 侧。U8 原来通向输入 R33 的采样连接应改接到新增电阻两端。
- 保留原模拟参数：电压增益 0.047；INA240A1 增益 20，零电流输出 2.5 V，电流增益 0.1 V/A；ADC 参考为 3.3 V。新板如改变这些参数，必须同步修改换算。
- PA10 = 左上管，PA11 = 左下管；PA8 = 右上管，PA9 = 右下管。两路驱动输入均按高电平有效。
- 该版本按双侧均只有自举供电设计。适用于本次正向 Buck / Boost；未实现反向控制。

## 已接入的执行链路

HRTIM A CMP3 → ADC1 注入序列（PA2 电流、PA0 VH、PA1 VL）→ 下一个 Timer B 周期中断 → `forward_step()` → Timer A/B 比较值预装载 → 下一周期共同生效。

- CPU/HRTIM 基础时钟 150 MHz，HRTIM 倍频 32，周期寄存器 32000：150 kHz。
- A/B 同时启动，两个周期相同；A 驱动右侧，B 驱动左侧。
- 硬件互补输出，双边正死区 200 ns；死区寄存器时钟为 150 MHz × 8，数值 240。
- ADC 时钟 37.5 MHz，每路采样 24.5 周期，加转换 12.5 周期；三路共约 2.96 μs。在周期 25% 处触发，在下一周期开始读取。
- ISR 不轮询 ADC，也不调用毫秒延时。主循环的 `adc_measurements` 为同步注入采样的换算结果。

自举刷新适配以有效上管占空比表示：Buck/预充电时，左侧 = `0.85 × D_cmd`，右侧 = `0.85`；Boost 时，左侧 = `0.85`，右侧 = `0.85 × (1 − D_cmd)`。这样保留理想平均电压变比，同时让两边下管均周期导通。比较值补偿 200 ns 的上管导通延迟。有效上管脉冲小于约 267 ns 时按最小脉宽处理；**停止通过关闭全部输出实现**。

这些设置采用 ST [AN4539 HRTIM cookbook](https://www.st.com/resource/en/application_note/an4539-hrtim-cookbook-stmicroelectronics.pdf) 中的互补输出、预装载和同步 ADC 触发机制。刷新时间是否满足实际自举充电条件，需要测量 HB–HS 电压确认。

## 启动和停止

上电运行采样与时间基准并显示首页，四路 PWM 输出均禁用。只有在参数页确认 `start` 才请求启动。

### OLED 与四按键

0.96 寸 OLED 按 128×64、6×8 字体显示。首页选择 `forward` 或 `reverse` 后，直接进入参数页，不再单独选择 Buck/Boost。

| 按键 | 浏览时 | 电压编辑时 |
| --- | --- | --- |
| KEY1 / PB4 | 向上循环选择 | 加 1 V |
| KEY2 / PB5 | 向下循环选择 | 减 1 V |
| KEY3 / PB6 | 进入、编辑或执行 start/stop | 确认保存 |
| KEY4 / PC13 | 返回首页；运行中先停机 | 取消本次修改 |

左列从上到下是 `input_v`、`output_v`、`start`；右列是只读的 `IL`、`intput_ret`、`output_ret`，分别显示电感电流、输入电压和输出电压，约每 200 ms 更新。`>` 为当前选择，`*` 为正在编辑。数值在标签下一行显示，底部显示状态或故障码。

`input_v` 是外部输入电源的标称设置，不会调节外部电源；范围 6～40 V。`output_v` 是闭环输出目标，范围 1～36 V。正反向各保留一组 RAM 参数，重新上电恢复默认：forward 12→36 V，reverse 36→12 V。

标题按已经确认的设置自动显示 `BUCK` 或 `BOOST`：输出低于输入执行 Buck，输出高于输入执行 Boost；两者相等时提示 `SET VIN != VOUT`，不启动。实际启动还会检查 ADC 实测输入电压与目标的关系；若标称设置与实际输入不一致，可能被拒绝启动。

选择 `start` 按 KEY3 后，先显示 `STARTING`，进入实际运行后显示 `RUNNING`，原位置变为 `stop`。再次确认 `stop` 或按 KEY4 返回均停机；启动准备阶段也可停止。启动/运行中不允许编辑电压。

reverse 页面可编辑设置和查看右侧输入、左侧输出电压，但本版没有反向控制，确认 start 只显示 `NOT IMPLEMENTED`。IL 的符号始终按物理左到右为正。无有效采样显示 `--`。

故障保持锁存并显示 `FAULT:位掩码`；菜单不自动清故障或重启，使用下面的调试命令显式清除后，再按 start。OLED 逐页传输，每轮主循环最多发送一页，传输与绘字不关闭 HRTIM 控制中断。

OLED 初始化使用 `20h + 02h` 的页寻址设置，与逐页传输相配合，见 [SSD1306 数据手册，第 10.1.3 节](https://www.olimex.com/Products/Modules/LCD/MOD-OLED-128x64/resources/SSD1306.pdf)。

### 调试器启停接口

在 Keil Watch 中查看 `power_status`，使用运行期间可更新变量的调试方式修改：

| 操作 | 变量赋值 |
| --- | --- |
| 正向 Boost，默认输出 36 V | `power_target_volts = 36.0`，然后 `power_command = 1` |
| 停止四路输出 | `power_command = 2` |
| 清除锁存故障，回到停止 | `power_command = 3` |
| 正向 Buck | 先设 `power_target_volts`，然后 `power_command = 4` |

主循环读取命令后会自动清零。清除故障不会自动启动。也可在前台代码调用 `Power_RequestStart(2U, 36.0f)`、`Power_Stop()`、`Power_ClearFault()`。

启动检查要求：至少两组采样有效，输入 6～40 V，输出目标 1～36 V，静态电流绝对值小于 0.25 A，**输出电容已放电至 0.25 V 以下**。当前按零输出冷启动设计，避免输出已有残压时小占空比预充电引起反向电流。Boost 要求输入小于目标，Buck 要求输入大于目标。启动先只开放两侧下管约 200 μs，等待比较值生效，再开放上管。

**带电运行期间不要断点暂停或单步控制 ISR。** 暂停 CPU 会让软件保护停止执行，调试器命令也需要主循环继续运行才能处理。

## 控制器适配与限值

沿用原 `forward.c` 的电压 PI、电流 PI、反馈滤波器、预充电和 Boost 状态机。为 MCU 做了以下修改，当前文件不再与 PLECS 原始导出文件逐字相同：

- 模型状态、接口和常量改为单精度，使用 Cortex-M4F 硬件浮点。
- `forward_configure()` 设置初始参考、目标和电流参考上限。Boost 参考从启动时输入电压开始，以 120 V/s 升到目标并保持；Buck 从 0.1 V 开始。
- 预充电结束门槛从 95% 输入改为 90%，避免停留在可达占空比边界；保留原三周期延迟和 Boost 电流参考渐入。
- 电压环参考电流上限暂设 6 A，预充电参考仍最多 2.5 A；增加 PI 条件积分，限制饱和时继续积累。
- 采样电流达到 7.5 A、PA2 接近 ADC 上下轨、反向电流低于 −1 A、输出超过目标 110%、输入超界、控制结果非法、ADC 序列缺失或计算超时，均关断四路输出并锁存故障。

6 A 是首轮软件参考上限。原采样电路 +8 A 已对应 3.3 V 满量程，因此留出裕量；本次没有把软件设置成能在 8 A 附近持续调节。输入 12 V、目标 36 V 时，负载过重会触及电流限制，不能保证升到目标。

`power_status.fault` 是位掩码：1=ADC，2=输入电压，4=输出过压，8=过流/电流 ADC 轨，16=反向电流，32=控制器，64=计算超时，128=启动条件不满足。`power_status.isr_cycles_max` 记录成功执行的最长 ISR 周期数；150 MHz 下一个 PWM 周期为 1000 个 CPU 周期。

PA2 反馈是固定相位的瞬时电感电流，不能直接当作平均值或峰值。软件电流门槛约束的是采样值，纹波峰值可能更高；需要结合实测纹波设置允许的负载和限流值。相邻中断进入时间也会检查，防止漏执行整个周期却被 REP/JEOS 的单个标志位掩盖。

当前没有配置比较器到 HRTIM Fault 的硬件逐周期过流通路。软件停机存在采样和计算延迟，不能代替硬件短路保护。

## 验证范围与后续实板检查

主机测试覆盖占空比映射、刷新窗口、非法命令、参考上限、状态复位，以及 22 μH / 690 μF / 36 Ω 平均模型下的正向 12→36 V 收敛。平均模型不包含 MOSFET 开关过程、死区体二极管、ADC 噪声、采样相位造成的电流纹波偏差和 PCB 寄生参数；不能作为实板稳定性证明。

另有理想开关数值测试，按实际电流采样相位和一周期预装载延迟运行同一控制器；它也不包含真实死区二极管导通和 INA240 瞬态响应。运行全部主机测试：在工程根目录执行 `./tests/run_tests.ps1`（需要 gcc）。

当前共七组主机测试。新增 `power_menu_test` 覆盖页面、电压编辑、自动模式和动作限制；`power_ui_test` 覆盖按键优先级、电源 API、逐页调度及调试器外部启停状态同步；`oled_render_test` 使用实际字库核对绘字边界、页寻址命令并导出预览。[菜单预览](docs/previews/oled-menu.png) 为主机生成的真实字库图，尚不是实板拍照。最新完整构建日志为 `MDK-ARM/menu_build.log`。

实板首次测试先观察四路逻辑 PWM 的引脚映射、互补关系和死区，再验证驱动输出及 HB–HS 电压、ADC 标定、启动电流和闭环波形。原 PI 参数尚未经过新板实测整定。

重新用 CubeMX 生成代码后，仍需核对 HRTIM 周期 32000、死区 240、Timer B CMP1 的 EQUAL 模式和 ADC AutoWait 禁用。注入 ADC、触发和中断设置由 `Power_Init()` 配置；中断入口与初始化调用放在 USER CODE 区域。
