- 主配置`POWER_MAIN_APPLICATION=1`、`POWER_MAIN_ADC_SOFTWARE_ONLY=1`，台架标志全为0。
  用户明确选择ADC软件保护测试；硬件OCP接线/就绪不伪造，当前未确认硬件保护。
- Buck菜单输入12–40V、输出0–36V，保持1V步进，默认正向24→12V、反向36→12V。
  非零后端目标1–36V；0V为关闭全部PWM、负载被动放电，不是主动0V稳压/放电。
  零请求可在准备/运行/故障时执行，取消待启动并保留首故障；正目标重启仍须新鲜样本与冷启动条件。
- 限流控制为电流参考上限6A；采样过流保留主工程原7.5A，为跟踪瞬态留余量。
  参考是电感采样控制目标，实际纹波/瞬时峰值和平均负载电流不等同该数值。

  36V目标对应45V；冷启动要求电流绝对值<0.5A、输出≤1V。
  Boost沿用原输入6–40V、目标1–36V、1.1倍OVP及0.25A/0.25V冷启动；反向Boost同原策略。
- 降压输出须低于实际输入。正向Buck请求及每次新样本均检查目标≤实际输入×0.95，
  36V可在40V输入下测试；12V输入下设置36V时菜单选择Boost。不可达的Buck请求拒绝启动，
  运行中输入跌至不可达时停机。反向Buck保留严格输出<实际输入及原HOLD/恢复流程。
- 正向Buck用优化控制步，正向Boost保留完整步，反向算法保留；共用一个步模板，

- 正向Buck和STOP显示使用ADC2晚PA0采样；活动Boost/反向继续原ADC1反馈时序，
  每周期清理不用的ADC2标志；需要的采样缺失/溢出仍停机。STOP/清故障使样本失效，重启需新样本。
